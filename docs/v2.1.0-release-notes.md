# Relay Console v2.1.0: English and French relay workflows

Relay Console v2.1.0 adds a complete English and French experience while
preserving the project's local, offline, single-file design.

## Highlights

- Choose the interface language and generated-prompt language independently.
- Use a French interface with English prompts, English controls with French
  prompts, or keep both in the same language.
- Run every built-in recipe with localized instructions: Debate, Blind, Ballot
  panel, Draft to Critique to Revise, Red team vs Blue team with judge, and
  Custom plan.
- Use native French `CLASSEMENT :` ballot lines while retaining compatibility
  with English `RANKING:` input.
- Export localized Markdown transcripts without changing captured questions,
  answers, participant names, custom roles, or edited forwarded context.
- Keep both language choices across reloads and saved sessions.

## Reliability and compatibility

- 51 automated checks pass across the released v2.0 file and v2.1.0.
- Full desktop, narrow mobile, reload, resume, ballot, scoring, synthesis,
  context-curation, prompt-editing, export, and accessibility checks passed.
- v1.x and v2.0 session files remain importable. Older sessions safely default
  to English prompts when language metadata is absent.
- A regression rule prevents em dashes from entering active product and release
  text.

## Privacy remains unchanged

Relay Console still has no backend, API keys, build step, account, trackers,
remote assets, or programmatic network calls. You remain in control of every
copy and paste between assistants.
