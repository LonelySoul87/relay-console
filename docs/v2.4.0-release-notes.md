# Relay Console v2.4.0: nothing is lost by accident

Relay Console v2.4.0 makes file review safer, long relays easier to navigate,
and local recovery more trustworthy while preserving the manual, offline,
single-file design.

## Highlights

- Review validated session or preset details before an import can replace work
  or change the saved preset library.
- Keep one bounded local recovery checkpoint for supported destructive actions,
  with direct Restore and Remove controls and automatic seven-day expiry.
- See the last successful autosave and estimated storage use without confusing
  a failed write with a successful one.
- Filter long transcripts by participant, turn type, round, state, or folded
  text, then revisit reached lane stations without changing captured answers.
- Inspect, rename, duplicate, and selectively export saved presets.
- Receive portable, date-stamped filenames and visible export confirmations.
- Open a localized keyboard-shortcut reference and use larger roster reorder
  controls, deliberate focus routing, and assistive-technology-safe lane input.

## Reliability and hardening

- Ballot displays, exports, and ranked filters now share one definition of a
  valid effective ranking.
- Import previews are text-only, do not mutate active data, and re-check preset
  storage immediately before applying changes.
- Oversize, expired, invalid, or failed recovery records cannot masquerade as a
  usable checkpoint or silently consume the only recoverable copy.
- Preset actions always target the option visibly selected, use one identity
  rule, and report storage or download failures accurately.
- Session, transcript, review-packet, and preset exports keep questions and
  answers out of filenames.
- Mouse, keyboard, and assistive-technology-style lane activation routes are
  behaviorally covered and never change captured answers.

## Verification

- 231 automated checks pass across the v2.0, v2.1, v2.2, v2.3, and v2.4 suites.
- English, French, and Spanish catalogs contain 431 matching keys with complete
  placeholder parity.
- Desktop, narrow-screen, keyboard, and responsive browser checks cover import
  review, recovery, preset management, transcript filtering, lane navigation,
  focus behavior, and the shortcut dialog.
- Active project and release-candidate text contains no em dash characters.
- `relay-console-v2.4.0.html` and `index.html` are byte-identical.
- The root checksum manifest contains nine ordered release artifacts and every
  entry is re-hashed from the actual file bytes during the v2.4 suite.

Two manual accessibility checks are not claimed: a real touch tap and a
listening session with NVDA or VoiceOver. Automated and browser evidence covers
the underlying input, focus, naming, live-region, and layout behavior, but it
does not replace those human checks.

## Privacy remains local

Relay Console still has no backend, model API calls, account, trackers, remote
assets, or programmatic network connections. A recovery checkpoint can remain
in the current browser for up to seven days unless removed sooner. Nothing is
uploaded by Relay Console, and the user remains in control of every handoff.
