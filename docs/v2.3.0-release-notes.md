# Relay Console v2.3.0: portable workflows and safer review handoffs

Relay Console v2.3.0 makes reusable workflows portable between browsers and
computers, and adds a compact handoff for independent review by ChatGPT,
Claude, or another assistant.

## Highlights

- Export up to 50 saved presets as one versioned JSON bundle and import them on
  another browser or computer.
- Keep preset bundles privacy-safe. They contain configuration only, never the
  current question, answers, generated prompts, forwarded context, or session
  nonce.
- Export a compact Markdown review packet containing the question,
  configuration, participants, roles, captured answers, actual context
  decisions, warnings, and ballot results.
- Review packets exclude generated prompts, use collision-resistant quoted
  material markers, and follow the generated-instruction language.

## Reliability and hardening

- Imported and existing local presets pass through the same strict validator.
- Imported names, roles, URLs, rosters, custom steps, rounds, and bundle sizes
  are bounded before storage or use.
- Only HTTP and HTTPS participant addresses survive preset validation.
- Preset imports are atomic and collision-safe. Existing names are never
  silently overwritten.
- Export keeps every valid preset when another stored entry is malformed and
  clearly reports the skipped entries.
- Loading a preset now restores and persists the complete setup.
- Interface-language changes preserve accurate quick-start guidance, while
  actual setup edits clear it.
- Review packets refer back to untrimmed captured answers instead of repeating
  their full text.

## Verification

- 130 automated checks pass across the v2.0, v2.1, v2.2, and v2.3 suites.
- English, French, and Spanish catalogs retain complete key and placeholder
  parity.
- Wide and phone-width browser checks cover the portable preset workflow,
  language behavior, review packets, quick starts, and status messages.
- Active project and release-candidate text contains no em dash characters.
- The release artifact and `index.html` are byte-identical.
- Earlier versioned artifacts and tags remain untouched.

## Privacy remains unchanged

Relay Console remains one standalone HTML file with no backend, API keys,
build step, account, trackers, remote assets, or programmatic network calls.
You remain in control of every copy and paste between assistants.
