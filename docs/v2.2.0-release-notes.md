# Relay Console v2.2.0: Spanish and faster two-model workflows

Relay Console v2.2.0 adds a complete Spanish experience, reusable embedded
language packs, and quick starts designed for people who already subscribe to
ChatGPT and Claude.

## Highlights

- Use the complete interface and every generated instruction in Spanish.
- Choose the interface language and generated-instruction language
  independently across English, French, and Spanish.
- Start with one of three editable ChatGPT and Claude workflows: Draft and
  improve, Compare independently, or Challenge a decision.
- Parse exact Spanish ballot lines using either `CLASIFICACIÓN:` or
  `CLASIFICACION:` while retaining the strict complete-ranking safety rules.
- Register embedded language catalogs through one validation path that checks
  every key and placeholder before the application starts.
- Keep automatically suggested role names aligned with the generated
  instruction language, even when the interface uses another language.

## Reliability and compatibility

- 86 automated checks pass across v2.0, v2.1, and v2.2.
- Wide English, wide Spanish, and narrow Spanish rendered layouts passed visual
  review without clipping, overlap, horizontal overflow, or broken accents.
- v1.x, v2.0, and v2.1 sessions remain importable. Older or unsupported locale
  values safely fall back to English.
- Accessibility labels, transcript exports, ballot parsing, all six recipes,
  quick starts, presets, role localization, and the offline privacy boundary
  are covered by regression checks.
- Active product and release files contain no em dash characters.

## Privacy remains unchanged

Relay Console remains one standalone HTML file with no backend, API keys,
build step, account, trackers, remote assets, or programmatic network calls.
You remain in control of every copy and paste between assistants.
