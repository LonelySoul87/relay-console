# Relay Console v2.5.0: relay across languages

Relay Console v2.5.0 adds complete German and Arabic workflows while preserving
the private, offline, single-file design.

## Highlights

- Use the full interface in English, French, Spanish, German, or Arabic.
- Choose the interface language and generated-prompt language independently.
- Run every relay recipe in German or Arabic, including strict localized ballot
  instructions.
- Use a right-to-left Arabic interface with mixed-language questions, names,
  answers, and web addresses handled deliberately.
- Export localized transcripts and review packets without translating or
  changing captured user content.

## Privacy remains local

Relay Console still has no backend, model API calls, account, trackers, remote
assets, or programmatic network connections. Language switching happens inside
the downloaded HTML file, and no text is sent to a translation service.

## Verification status

The release candidate passes 127 dedicated checks and all 358 current and historical
checks. Live desktop, 390-pixel, and 320-pixel browser passes cover German,
Arabic, mixed-direction input, wrapping, clipping, horizontal overflow, and the
browser console. Released v2.4 surfaces remain unchanged.

Independent implementation review is complete. Automated catalog parity does
not by itself prove that every German or Arabic phrase is natural to a fluent
reader.

An evidence-backed catalog-wide language audit has now corrected the known
Arabic dual, recovery-verb, point-count, and technical-terminology problems,
along with a focused set of German grammar, accessibility-name, and clarity
problems. Native-tone and regional-preference feedback remains welcome through
the public issue forms, with a reminder not to include private relay content.

The release does not claim fluent-human Arabic review, fluent-human German
review, a screen-reader listening session, or a physical touchscreen test.
Automated focus, accessible-name, live-region, keyboard, target-size, reflow,
catalog, prompt, and grammar checks pass. Under the project acceptance policy,
these four unavailable human checks are documented post-release feedback areas
rather than release blockers.

The app links directly to privacy-aware GitHub bug and feature forms. GitHub
issues are public, so the app and the forms both tell reporters not to include
private questions, answers, provider conversations, or session files. Suspected
security and privacy vulnerabilities continue to use the private security
contact instead.
