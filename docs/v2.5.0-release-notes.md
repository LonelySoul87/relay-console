# Relay Console v2.5.0: relay across languages

Status: development draft. Do not publish this text as final release notes yet.

Relay Console v2.5.0 adds complete German and Arabic workflows while preserving
the private, offline, single-file design.

## Highlights

- Use the full interface in English, French, Spanish, German, or Arabic.
- Choose the interface language and generated-prompt language independently.
- Run every relay recipe in German or Arabic, including strict localized ballot
  instructions.
- Use a right-to-left Arabic interface with mixed-language questions, names,
  answers, and web addresses handled deliberately.
- Export localized transcripts and review packets without translating or
  changing captured user content.

## Privacy remains local

Relay Console still has no backend, model API calls, account, trackers, remote
assets, or programmatic network connections. Language switching happens inside
the downloaded HTML file, and no text is sent to a translation service.

## Verification status

The current draft passes 122 dedicated checks and all 353 current and historical
checks. Live desktop, 390-pixel, and 320-pixel browser passes cover German,
Arabic, mixed-direction input, wrapping, clipping, horizontal overflow, and the
browser console. Released v2.4 surfaces remain unchanged.

Independent peer-language and implementation review remains open and must be
completed before publication. Automated catalog parity does not by itself prove
that every German or Arabic phrase is natural to a fluent reader.
