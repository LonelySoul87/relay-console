## Independent scope audit

- Claude Code independently verified the scaffold and automatic test discovery.
- The audit selected **Nothing is lost by accident** as the v2.4 release theme.
- Four inherited defects were reproduced: invalid ballot recovery, disagreement
  between ballots and exports, unconfirmed resume discard, and focus loss after
  changing the interface language during a relay.
- Language expansion moved to v2.5, right-to-left support remains a separate
  architectural decision, and generated diagnostics were rejected.

## First implementation checkpoint

- Fixed invalid ballot recovery. A rebuilt dropdown now starts from the visible
  label set, and a manually corrected ballot always offers direct re-parsing.
- Added one validated ballot helper shared by the tally, transcript badge,
  transcript export, and review packet so they cannot disagree about whether a
  ranking counts.
- Added confirmation before the saved-session Discard action can erase its local
  autosave.
- Preserved focus on the interface-language selector during an active relay.
- Added a modal import preview for sessions and preset bundles. Files are fully
  validated before preview, and nothing changes until the user explicitly
  applies the import.
- Session previews show version, participants, turns, captured answers, current
  position, plan, and both languages.
- Preset previews show each normalized preset and warn about collision renames,
  removed unsafe URLs, and shortened roles.
- Imported strings are rendered with `textContent`; the active artifact still
  has exactly one non-empty `innerHTML` assignment, limited to trusted catalog
  copy.
