# Relay Console v2.2.0 release audit

Audit date: 2026-08-23

Branch: `develop/v2.2.0`

Artifact: `relay-console-v2.2.0.html`

## Result

**PASS for release.** Final naming has been applied, the release-candidate
visual gate is complete, all automated checks pass, and the owner authorized
the complete publication workflow.

The release keeps the project boundary intact: one standalone HTML file, zero
runtime dependencies, no backend, no API keys, no remote assets, no trackers,
and no programmatic network calls.

## Scope completed

- Added a locale registration system with key and placeholder validation.
- Registered complete English, French, and Spanish catalogs.
- Added a complete Spanish interface, generated instructions, alerts,
  accessibility labels, recipes, and Markdown transcript exports.
- Added strict accented and unaccented Spanish ballot parsing.
- Added three editable ChatGPT and Claude quick-start workflows.
- Preserved separate interface and generated-instruction language choices.
- Kept known automatic role names aligned with the generated-instruction
  language independently from the interface language.
- Preserved v1.x, v2.0, and v2.1 session import compatibility.

## Problems found and fixed during the audit

1. Known automatic role names could follow the interface language instead of
   the generated-instruction language. Role localization now follows the
   instruction language independently, with regression coverage.
2. Direct automated inspection of the local-file preview was refused by the
   browser controller's URL policy. No bypass was used. Wide English, wide
   Spanish, and narrow Spanish screenshots from the actual release candidate
   completed the visual gate.
