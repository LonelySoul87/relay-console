    Participants

    Order matters to most plans. The URL powers the one-click launch each turn. Roles get woven into that model's prompt; each slot starts with a recommendation. Your roster is remembered between sessions.

    The plan

    One round = everyone speaks once. Every turn re-reads the transcript, so watch the token counter.

    Custom steps (top to bottom is the running order)

    Answer sees the discussion so far. Blind sees only the question. Revise shows a model its own earlier answer plus everything said since. Ballot asks for a ranking of the answers so far. Synthesize merges everything.

    Optional. Leave it open and you can still paste the synthesis prompt anywhere when you get there.

    Presets

    A preset stores your roster, recipe, custom steps, rounds, and format under a name. It never stores your question or any answers. Saved locally in this browser only.

    Peer ranking

    Borda tally of the models' own pasted rankings: with n answers, 1st place earns n−1 points, last earns 0. Only confirmed ballots count.

    Transcript

    The text here is the answer you captured. Trimming what's sent forward never alters this copy or the exports; it only changes what later models receive. Grid view lays answers side by side for honest comparison.

    Review packets contain every captured answer in full, even when context was trimmed or excluded. Check for sensitive information before sharing. Trimming is not redaction.

    Relay Console runs in your browser and never uploads your questions, answers, or session data. It opens a provider website only when you explicitly choose Copy & open. Anything you paste into that provider is handled under its own terms.
    Autosave keeps your session when you run this as a saved .html file. Inside a preview it may not persist, so use Save file for a hard backup.
    Before a restart, a discard, or opening a file over your work, Relay Console keeps one local recovery copy in this browser. Discarded or replaced work can therefore remain in local browser storage for up to seven days unless you press Remove. It is never uploaded.
    Shortcuts: Ctrl+Enter saves & advances · Ctrl+Shift+C copies the current prompt · Esc closes the add-chatbot menu.
